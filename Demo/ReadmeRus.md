# Demo

![demo](demo.png)

В данной директории находится демонстрационный проект (восстановленный нетлист Nintendo MMC1) для знакомства с Deroute.

Картинку чипа можно загрузить через меню File -> Load Image и выбрать `MMC1_20X_Fused_sm.jpg`

Сущности составляющие нетлист можно загрузить через меню File -> Add entities и выбрать `mmc1.xmlz`

Сохранить нетлист микросхемы как Verilog можно через меню File -> Export to Verilog и указать например `mmc1.v`
